# results/

Generated by `python eval/evaluate.py --labels <labels.csv>`, which runs the real detector on
labelled videos. Nothing here is written by hand.

- `metrics.json`: measured results, marked `"provenance": "measured"` (the app shows nothing else)
- `misses.json`: every wrong verdict and the detector's reason
- `per_file.csv`: one row per video
- `REPORT.md`: readable summary

An earlier version of this folder held numbers produced by a simulator (`eval/run_all.py`
generated scores from random draws instead of running the detector). They were removed on
25 Oct 2026 and must not be quoted.
